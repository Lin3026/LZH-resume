# 地下城与勇士：起源

# 研发公司

《地下城与勇士》Dungeon \& Fighter，国内简称DNF。它是由韩国NEOPLE于2004年研发，2005年8月上线。最高同时在线人数接近30万。

腾讯在2003年上线了QQ游戏大厅，并代理韩国3D游戏《凯旋》宣布正式进军游戏行业。

2008年拿下的中国代理权。上线首日在线人数19万，随后半年时间，在线人数突破200万人，是当年最火热的网游。

# 游戏介绍

DNF是一款2D卷轴式横版格斗过关网络游戏 ，继承家用机、街机2D格斗游戏的特色（街机三国志，拳皇），真正实现了在线格斗体验；游戏以任务引导角色成长为中心，结合副本、PVP、PVE为辅的玩法。

# 游戏背景

在一个叫阿拉德大陆的地方，上面住着一群人类，天上的虚空异界住着一群精灵。为了他们只能方便往来建造了一个叫天空之城的枢纽。其中有个大反派叫巴卡尔为了抢夺“生命之水”（长生不老药），发动了龙之战争。那是一场天地变色、伤亡惨重的毁灭之战，鲜血染红了魔族的土地，战败的巴卡尔逃亡天界，切断了大陆通往异界的所有通道，从此人类和精灵彻底决裂。为了打赢反派阿拉德大陆上的冒险家们纷纷投入到这场战斗之中。

# 养成系统

![Luban\_17311333518319ac79927\-1726\-42cc\-a772\-3c70524ff7a0\.jpg](competitor/dnf-assets/dnf-006.jpg)

### 宠物

游戏中宠物能帮助玩家进行战斗，宠物出战时，会提高角色的力量、智力、体力、精神。宠物升级后，可以获得更多属性值。可以通过商店购买等多种方式获得宠物

![Luban\_1731137704348648650b4\-a822\-4593\-b7cb\-a111c11afc0b\.jpg](competitor/dnf-assets/dnf-008.jpg)

![Luban\_17311376090939701c3ad\-5ea5\-4557\-a5a4\-90a98a2cf4ea\.jpg](competitor/dnf-assets/dnf-007.jpg)

### 装备

游戏中有着多种装备，分为装备、称号、勋章三种类型，装备可以提高角色的各项属性，系统统一以抗魔值进行显示，抗魔值越高，装备越好。玩家可以通过刷图、打造等多种方式获得。

![Luban\_1731138463679756fe12f\-ee29\-43ee\-a05d\-a455610e440c\.jpg](competitor/dnf-assets/dnf-009.jpg)

### 装扮

穿戴装扮后，可以改变角色外观，装扮的属性和外观可以分别应用。属性栏中穿戴装扮可以同时应用装扮的外观和属性值。幻化栏中穿戴装扮只应用装扮的外观，就是外套和内搭的区别，外套没有属性加成，内搭有属性加成。

# 强化系统=打工系统

### 制作：可以制作游戏中所有的装备，制作所需要的材料，需要去刷图才能获得。保证了平民能追得上大佬的魔抗。

![Luban\_1731139565759e8608c59\-1685\-4e2a\-a531\-efeadf19ec61\.jpg](competitor/dnf-assets/dnf-013.jpg)

### 强化：强化装备，增加角色的属性值。游戏增加了保底机制，减少玩家强化次数。强化需要的材料炉岩碳需要去刷图获得，每天刷图打工。

![Luban\_1731139570602ff6b9fa2\-3b92\-49ab\-9dbb\-ae9cac1137de\.jpg](competitor/dnf-assets/dnf-014.jpg)

### 继承：可以把同部位的装备互相转换强化等级，减少玩家刷装备时间。

![Luban\_1731139575160bd16f2d7\-b33e\-45a2\-b02b\-9ad7e9c3dc20\.jpg](competitor/dnf-assets/dnf-015.jpg)

# PK系统（公平竞技）

#### PK场内：装扮属性，装备强化都不起作用，只能依赖角色本身基础属性，所有人的等级都一样，血量都差不多。

1\.单人排位：1v1，谁胜利就加积分

2\.勇士激战：2v2，休闲对战，没有加积分，鸡肋玩法

3\.擂台赛：分红蓝两队，打车轮战1v1，哪方先打赢三个人，哪方获胜。可以加积分
